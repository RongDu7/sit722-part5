# IoT Vehicle Health Monitor

A Python-based IoT system for vehicle asset tracking and health monitoring.  
Implements modular microservices with containerized deployment using **Docker Compose**.

## Features
- Data ingestion from IoT sensors and simulated devices  
- Book catalog and inventory management microservices  
- Container orchestration and dependency management with **Docker Compose**  
- API endpoints developed with **Flask** and **Pipenv**

## Tech Stack
Python · Flask · Docker Compose · Pipenv
